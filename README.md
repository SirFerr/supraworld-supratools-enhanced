# SupraTools Enhanced for Supraworld

Русский | [English](README.en.md)

Модифицированная версия **[SupraTools 1.0.3](https://github.com/joric/SupraTools) от joric**, с защитой игрока, поиском предметов и светящимися 3D-маяками. Оригинальные инструменты SupraTools сохранены. Это самостоятельная модификация сообщества; joric не отвечает за добавленные функции.

## 1.1.2 — исправление загрузки горячих клавиш

Ошибка подключения защиты к `IsImmuneToDamage?` больше не прерывает загрузку меню и поиска (Alt+H, Alt+B и Alt+стрелки). Если UE4SS не может подключить защиту, Alt+K сообщает `UNAVAILABLE`; неуязвимость в таком случае не работает. Установщик пересобран с исправленными исходниками, версия UE4SS сохранена.

Проверены синтаксис Lua и сценарии отказа/повторного подключения на моделях. Исправление пока не проверено в игре.

## Что добавлено

- Единая панель справки и поиска на **Alt+H**.
- Категории: страницы Solvers' Guide, секреты, монеты, подарки и яйца способностей.
- Собранные страницы и открытые яйца исключаются из поиска.
- Дубли секретных зон в радиусе 1,5 м от яйца убираются. Близкий независимый секрет тоже может попасть под этот фильтр.
- Скрытые яйца и награды, замеченные до сбора и затем уничтоженные, исключаются. Проверка полного владения через инвентарь не выполняется; после загрузки сохранения результат зависит от сохранённого состояния яйца.
- Маяки — реальные объекты мира высотой около **10 км**, с отдельным цветом категории и свечением. У них нет столкновений, физики и теней.
- Подписи с расстоянием, тенью, привязкой к точке предмета и разнесением при наложении. Положение обновляется на игровом кадре.
- Защита локального игрока от обычного урона, включена по умолчанию.
- Один установщик со встроенными UE4SS и SupraTools, проверкой файлов, резервной копией и скриптом отката.

| Категория | Цвет |
|---|---|
| Страницы | Голубой |
| Секреты | Зелёный |
| Монеты | Золотой |
| Подарки | Розовый |
| Способности / яйца | Фиолетовый |

Категория способностей отмечает объекты `ShopEgg_C` и `ChocolateEgg_C`. Она не является полным каталогом всех сюжетных наград или покупаемых улучшений. После разрезания яйца / раскрытия шоколадной оболочки соответствующая оболочка скрывается из поиска. Поиск видит объекты, загруженные игрой; число в меню не означает полный остаток предметов во всей игре.

## Установка

1. Закройте Supraworld.
2. Скачайте **[Install-SupraTools.ps1](https://github.com/SirFerr/supraworld-supratools-enhanced/raw/refs/heads/main/Install-SupraTools.ps1)** или возьмите файл из [релиза](https://github.com/SirFerr/supraworld-supratools-enhanced/releases/latest).
3. В папке с файлом откройте PowerShell и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-SupraTools.ps1
```

Если Steam установлен в необычной папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-SupraTools.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Supraworld"
```

Проверка встроенного пакета без установки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-SupraTools.ps1 -VerifyOnly
```

Скрипт создаёт резервную копию в `Supraworld\Binaries\Win64\SupraTools-backups` и выводит её путь. Для отката закройте игру и запустите `Restore.ps1` из этой резервной копии. Существующие настройки UE4SS и другие моды сохраняются. Если обнаружен другой загрузчик `dwmapi.dll`, установка останавливается. Скрипт не запускает игру и не меняет сохранения, DLSS или MFG Bridge.

## Управление

| Клавиши | Действие |
|---|---|
| Alt+H | Открыть / закрыть единую панель |
| Alt+← | Переключить вкладки справки и поиска |
| Alt+↑ / Alt+↓ | Выбрать строку поиска |
| Alt+→ | Изменить выбранную настройку |
| Alt+B | Включить / выключить 3D-маяки |
| Alt+M | Миникарта SupraTools |
| Alt+K | Включить / выключить защиту игрока |
| F10 | Консоль |

Маяки изначально выключены. В меню можно выбирать категории, радиус 50 / 200 / 500 / 1000 м и максимум 8 / 16 / 24 маяка. Настройки поиска сохраняются локально в `%LOCALAPPDATA%\Supraworld\SupraSearch.ini`.

В консоли доступны `supra_search`, `supra_search beams`, `supra_search abilities`, `supra_search radius 1000` и `supra_search status`.

## Совместимость и проверки

Целевая версия: **Supraworld build 12678, Unreal Engine 5.7.4, Windows / Steam**. Игра в раннем доступе: обновления могут изменить классы объектов и работу UE4SS. Защита работает через игровой запрос иммунитета; сюжетные переходы, принудительная смерть или выход за границы мира могут обходить обычный урон.

Проверены синтаксис Lua, фильтрация собранных страниц и открытых яиц, выключение категории способностей, разнесение 16 подписей, целостность встроенного пакета, установка в отдельную тестовую папку и точное восстановление исходных файлов. Результат проверки в игре описан в [VALIDATION.md](VALIDATION.md).

## Исходники и сборка

`SupraTools/Scripts` содержит все исходники модифицированного мода. Для ручной установки с уже настроенным UE4SS скопируйте папку `SupraTools` в `ue4ss/Mods` и включите мод в `mods.txt`.

Установщик собирается Python 3 из подготовленной папки игры с runtime UE4SS, встроенными консольными модами и этими исходниками:

```powershell
python tools/build_installer.py --win64 "D:\SteamLibrary\steamapps\common\Supraworld\Supraworld\Binaries\Win64" --output Install-SupraTools.ps1
```
